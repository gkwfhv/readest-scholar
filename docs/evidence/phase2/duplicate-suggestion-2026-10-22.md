# Phase 2：文献元数据重复提示（2026-10-22）

Scholar 元数据编辑页现在只给出提示，不自动合并书籍、文献 ID、文件、笔记或批注。相同 DOI 优先匹配；没有相同 DOI 时，仅在标题、作者和出版年份均匹配时提示。比较 DOI 时忽略大小写及常见 `doi:`、`doi.org` 前缀；排除当前书籍、软删除书籍和明确不同的 DOI。

## 已验证

- 先写失败测试：既有 DOI 匹配在编辑页没有提示。实现后，纯匹配规则及编辑页回归测试通过，保存按钮仍可使用。
- Node 24 全量 Vitest：1,180 个文件通过、4 个跳过，13,836 个测试通过、16 个跳过；TypeScript 与 Biome 检查通过。实际 Scholar Web 页面使用本地测试书库：在第一本书保存测试 DOI，第二本书输入同一 DOI 的另一种大小写和 URL 写法，编辑页即时出现含第一本书书名的中文提示。检查了默认桌面宽度和 390 px 视口，提示框及信息图标未溢出；随后取消第二本书的编辑并清除第一本书的测试 DOI。

## 尚未通过的 Phase 2 验收

一次 201 份合成 PDF 的浏览器批量导入尝试停在自动化文件选择器，未产生可验证的导入结果，因此不能计作 200+ 文献验收。尚需通过稳定的真实导入入口验证规模、跨 Web/桌面同步和账户隔离。此提示只比较当前客户端已加载的书库，尚未将相似文件自动映射到同一逻辑文献。
