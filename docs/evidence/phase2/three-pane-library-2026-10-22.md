# Phase 2：三栏科研书库实测（2026-10-22）

## 构建与测试

- 以 `ef7e4214c` 为基线，在 Scholar 构建中加入仅宽屏可选的科研书库视图：左侧嵌套文献集和计数，中间文献列表，右侧复用现有元数据详情。普通 Readest 构建仍保留原书架。
- 纯数据测试覆盖 203 本可见文献、嵌套集合、空集合、删除记录和相似前缀隔离；交互测试覆盖集合切换、文献选择、打开/编辑回调和空状态。窄屏菜单测试先在旧行为下因仍显示“科研书库”而失败，修复后通过。
- Node 24 的 TypeScript 检查、全仓 Biome lint 和 Scholar Web `next build --webpack` 通过。生产构建第一次触及 Node 默认约 4 GB 堆上限；设置 `NODE_OPTIONS=--max-old-space-size=8192` 后构建完成。最终代码的全量 Vitest 为 1,183 个文件通过、4 个跳过；13,840 项测试通过、16 项跳过，0 失败。

## 实际界面

本机运行上述生产 Web 构建，浏览器使用原有合成测试会话；Auth/REST/对象存储仅通过 SSH 隧道连接隔离 Linux staging。未把这个分支部署到运行中的 staging Web，未使用生产账户。

- 1280 × 720 浅色界面中，合成 `Scholar Scale` 集合显示 201 本，`Batch A` 为 100 本，`Batch B` 为 101 本；选择 `Scholar Scale Paper 150` 后右栏更新标题、DOI `10.5555/scholar-scale.150` 与两个合成标签，栏位未超出窗口。[浅色截图](readest-three-pane-light.png)。
- 同一宽度的暗色界面中，三栏与所选集合保持可读。[暗色截图](readest-three-pane-dark.png)。浅色 E-Ink 模式下，集合按钮及操作按钮有清晰边框，三栏保持对齐。[E-Ink 截图](readest-three-pane-eink-light.png)。测试后已将主题恢复为自动，并关闭 E-Ink 模式。
- 390 × 844 手机视口回退到现有网格书架；视图菜单不再提供无法显示的三栏选项。[手机回退截图](readest-three-pane-mobile-fallback.png)。浏览器视口已恢复默认值。
- 浏览器总数为 205，含此前保留在本地的两本书和另外两本已有测试书；此数不是服务端 201 份新导入 PDF 的计数。数据规模和账户隔离的服务端验收另见 [规模证据](scale-cross-device-2026-10-22.md)。
