# Phase 3：Scholar 文件缓存模式与完整镜像（阶段性证据）

日期：2026-10-23。环境：服务器 `/home/gavin/readest-scholar-dev` 的构建容器、隔离 Linux CEF QA 容器、合成账户和回环候选 Web。没有在本机开发、编译或推送代码。

## 实现

- 每个设备按 Scholar 账户保存“按需下载”（默认）或“完整镜像”偏好；入口位于客户端“设置 → 集成 → Readest Scholar”。切换账户不会继承另一账户的偏好。
- 完整镜像在书库加载后检查文件是否实际存在，缺失时加入现有持久化传输队列；新同步到书库的云端文件同样入队。失败任务留在队列供人工重试，不产生无限自动重试。关闭完整镜像会取消该账户尚未完成的自动镜像任务，不影响用户手动下载。
- Scholar 下载任务记录入队账户，在下载前后校验账户；旧版没有账户信息的 Scholar 下载任务明确失败并提示重排。远端上传时间比本地下载时间新时，镜像下载替换旧文件；下载本身沿用已实现的不可变版本、大小和 SHA-256 校验。
- 移动端自动镜像只在明确识别 Wi-Fi／以太网且未开启节省流量时启动；无法识别网络类型时保持按需下载。网络变化会重新扫描，离开允许网络时把自动镜像任务标记取消。底层已开始的下载 API 尚无中断信号，可能完成当前文件的传输；该边界必须在移动真机网络切换验收中验证。

## 边界

网络类型 API 在部分移动 WebView 不可用，因此其自动完整镜像会保守停用。当前实测仅覆盖 Linux 客户端和一个合成 PDF；200+ 文献规模、移动真机、双设备文件更新和长时间后台运行仍需在后续 Phase 3/7 验收中补齐。此文件不表示 Phase 3 已签收。
