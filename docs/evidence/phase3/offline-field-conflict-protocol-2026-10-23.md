# Phase 3：离线字段重放与冲突版本基础（2026-10-23）

范围：服务器本地开发分支 `feat/scholar-offline-metadata`；没有 GitHub/GHCR 推送或 staging 正式栈升级。Phase 3 尚未验收。

## 实现

- 新推送请求标记 `protocolVersion: 2`。服务端对设置、OPDS、ABS、翻译器和 TTS 等纯字段元数据允许旧 HLC，保留原始字段时钟；仍限制未来时钟，并拒绝畸形时钟。旧协议保持原来的偏差窗口。
- 文件清单、删除、复活、书架和二进制资源仍维持原保护：旧待发送操作不会改写成当前时间，也不会作为已解决冲突提交。
- 客户端在清除已提交的持久队列之前检查合并结果，将落败字段的本地版本保存到按账户隔离的本地冲突记录；记录失败会保留队列。重复提交用稳定字段键去重。
- 迁移 034 新增账户隔离的只追加历史表。旧服务端行被新内容覆盖时由触发器保存；新版 RPC 另外保存未赢的迟到提交。旧 RPC 保留给已安装客户端。
