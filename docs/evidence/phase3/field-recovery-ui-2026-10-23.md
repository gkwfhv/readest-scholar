# Phase 3：单字段冲突恢复与并发保护（2026-10-23）

**范围：服务器本地分支和 SSH 隧道内的合成 staging。Phase 3 整体未验收。无 GitHub/GHCR 上传，无公网端口。**

## 实现

- 迁移 036 增加账户校验的 `restore_replica_field_v1`：仅允许纯元数据副本、指定历史版本和字段，比较当前字段的完整 envelope；行锁内以新 HLC 恢复，并把被替换的版本归档。旧二进制、删除与复活语义不在此 RPC 中恢复。
- “管理同步”新增按账户读取最近 50 条历史的恢复区；敏感字段（令牌、密码、密钥、用户名、授权头及加密 envelope）只显示遮罩，不能点恢复。中文简体/繁体标签已补齐。
- 展开一条记录时先读取当前服务端副本；核对期间按钮禁用。点击时客户端再次读当前字段，与展开时的版本比较；若已变化，返回 40001 提示用户刷新。数据库 RPC 再在提交时做 CAS，保护第二段并发窗口。
